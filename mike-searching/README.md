# MIKE searching

Reusable Codex skill for FlavorWise creator and B2B partnership development.

It covers:

- partner research, archetype classification, and evidence-based scoring;
- Revenue/Authority and Revenue/Strategic prioritization;
- Bias Shield, forecast, expected value, and `APPROVE / NEGOTIATE / WAIT / REJECT` decisions;
- localized first outreach, reply handling, and low-friction follow-up;
- pipeline records, outcomes, prediction error, experiments, and learning.

This package is intentionally de-identified. It contains no customer list, private contact data, private messages, account history, or client-specific commercial terms. Replace bracketed placeholders at runtime and verify current product/commercial facts before external use.
