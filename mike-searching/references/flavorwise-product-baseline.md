# FlavorWise product baseline and claim control

This file contains only stable, public-safe product language. It is not a substitute for the current official catalog or User Manual.

## Safe baseline

- Brand: `FlavorWise`
- Product: `CH-172A Plant Processing and Storage Cabinet`
- Brand expression: `Make Flavor Consistent.`
- Category description: `3-in-1 Drying + Curing + Storage`
- Capacity wording: roughly `8-10 lbs wet flower capacity`
- Modes: Drying, Curing, Storage, and Full Cycle
- Public product page: `https://flavorwisetech.com/`
- Public manual: `https://flavorwisetech.com/wp-content/uploads/2026/07/User-Manual.pdf`

When relevant, say that temperature, humidity, and stage duration can be configured only if the current official product source confirms the exact capability. Use the official source for precision, app behavior, environmental limits, warranty, stock, delivery, and other technical details.

For a current draft, source priority is: latest explicit user authorization → latest formal quote/contract → current official catalog/manual/site. Historical snapshots are context only and must be marked `STALE-RISK`.

## Claim governance

Do not promise or imply the following without current, appropriate evidence:

- terpene retention;
- aroma improvement;
- flower-quality improvement;
- mold prevention;
- guaranteed consistency;
- drying-speed advantage;
- laboratory superiority;
- guaranteed results.

Turn unverified outcomes into evaluation language: `worth testing in your workflow`, `we can see how it performs under your conditions`, or `the final judgment should come from the test`. Never upgrade `may be relevant to evaluate` into a guaranteed benefit.

## Commercial boundary

Do not embed current wholesale price, retail price, MOQ, margin, freight, tax, payment, warranty, replacement, territory, exclusivity, discount, or delivery promises in a reusable template. These are time-sensitive and must be confirmed for the specific market, quantity, destination, and collaboration format before external use.

Do not describe a product as an available large cabinet, a guaranteed shipment, or a confirmed regional program unless the current official source and user authorization support that wording.

## Product bridge rule

For a first outreach, the product bridge should normally fit in one or two sentences:

`FlavorWise makes a 3-in-1 Drying + Curing + Storage cabinet for roughly 8-10 lbs wet flower capacity.`

Add a workflow-specific sentence only when the Content Anchor supports it. Keep product information secondary to the recipient's content, audience, customer, or work.
